# FORMA MCP website

The standalone product landing page for [FORMA MCP](https://github.com/EgoisticCoder/Forma_MCP), a Playwright browser and UI/UX inspection toolkit for MCP-compatible IDEs and agents.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, then serve it with `npm start`. The site is a Next.js app and can be deployed to Vercel or another Node.js-compatible host.
